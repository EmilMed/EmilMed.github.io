Added distance-aware volume shaping and motion smoothing to improve localisation accuracy by 18%. Built a pilot testing harness that logged telemetry to PostgreSQL dashboards for iterative tuning.

ZER0x – Zero-Proof Password Manager

ToonDoc – AI Child Healthcare Voice Assistant

Engineered a conversational AI agent with Mistral LLM, ElevenLabs audio, Twilio messaging, and Langflow orchestration. TrafficGuard – DDoS Detection Model

Instrumented feature drift dashboards in Grafana to monitor live traffic and curbed false positives by 22%. Deployed the inference service on FastAPI with Redis caching for sub-50 ms responses.
